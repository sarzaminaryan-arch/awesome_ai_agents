# تصاویر شاخص — شهرستان‌های خراسان رضوی

سیاست تصویر (طبق درخواست کارفرما): برای هر شهرستان یک **تصویر سینمایی حرفه‌ای ساختهٔ هوش مصنوعی، کاملاً واقع‌نما، از نمای بالا از یک جای معروف همان شهر** جایگزین می‌شود؛ اگر چنین تصویری ممکن نبود، تصویر تمیز و حرفه‌ای گوگل‌مپ‌مانند. کارتونی/غیرواقعی و عکس‌های هوایی غیرآزادِ آرشیوی ممنوع‌اند.

مشخصات فنی: خروجی مدل ۱۵۳۶×۱۰۲۴ → برش `1536x864+0+80` → تغییر اندازه به ۱۶۰۰×۹۰۰ → `unsharp` → WebP کیفیت ۸۴.
